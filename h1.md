# Sniff  
  x)   Wireshark:<br> 
  <br>
      -Wireshark is a network sniffer and analyzer used to capture network traffic and view statistics.<br> 
      -Wireshark statistics show a list of endpoints, I/O graphs and hierarchy of used protocols.<br>
      -Filters can be used to sort the capture in a desired way.<br>
      <br>
      Network interface names on Linux:<br>
      -A network interface is basically like a network card, but it doesn't have to be an actual piece of hardware.<br>
      -en means wired ethernet.<br>
      -wl means wlan/wifi.<br>
      -lo means loopback adapter.<br>
      -To check your interfaces you can use such commands: ip a or ip route.<br>
      <br>
      References: https://terokarvinen.com/wireshark-getting-started/ <br>
      https://terokarvinen.com/network-interface-linux/

  b) Disconnecting VM's connection:<br>
  <br>
    1) First option is to go to VirtualBox Manager and to your VM's settings. Choose expert and then network. Under network<br> 
    there is a checkbox checked with text "Virtual Cable Connected" next to it. By unchecking this box, the connection<br> 
    of the VM will be terminated.
    <br>
    <br> 
    2) Second option is to open your VM. On VM's desktop on top right corner, there is and icon right on the left of<br>
    date and time. When you hover over this icon, this text appears: "Ethernet network connection "Wired connection 1"<br> 
    active". By right-clicking this icon a drop down menu opens with few options. The first checkbox option (on xfce) is<br> 
    "Enable Networking". By unchecking this box, the connection of the VM will be terminated.
